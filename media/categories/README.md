# Category background photos

Drop category photos here. The site picks one automatically from the material a
customer chooses (RFQ form) or the tab they open (suppliers directory). Any file
that is missing simply falls back to the brand gradient — nothing breaks.

**Format:** `.webp`, landscape, ~1600×900 (16:9) or wider. Keep each under ~200 KB
(audience is often on mobile data). Shot/cropped so the subject reads even with a
dark or cream overlay on top.

**Exact filenames** (keyword shown → maps from these Arabic labels):

| File | Matches labels containing |
|---|---|
| `rebar.webp` | حديد (حديد تسليح، الحديد) |
| `blocks.webp` | بلوك / إنترلوك (البلوك والإنترلوك) |
| `concrete.webp` | خرسان (خرسانة جاهزة) |
| `brick.webp` | طوب (الطوب الأحمر) |
| `insulation.webp` | عزل (مواد العزل) |
| `aggregate.webp` | رمل / بحص / حصى (الرمل والبحص) |
| `cement.webp` | سمنت (أسمنت، الإسمنت) |
| `timber.webp` | خشب / أخشاب (الأخشاب) |
| `plumbing.webp` | سباكة / أنابيب / مواسير / صرف |
| `electrical.webp` | كهرباء / إنارة |
| `machinery.webp` | معدات / ثقيل / حفر / رفع / تمهيد / سفلتة / شاحنات |
| `ceramic.webp` | سيراميك / بلاط |
| `doors.webp` | أبواب / باب |

The mapping lives in `index.html` (search `catBgSlug`). Add a row there if you add
a new material option.
